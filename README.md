# 인재관리 포털 기능 확장 — 급여명세서·계약서 자동 작성·폼 자동 채움

고객사의 기존 인재관리 포털(모델 기반 앱)에 급여명세서 관리, 근로계약서 자동 작성, 폼 자동 채움 기능을 설계해 붙인 작업이다.

> 회사 업무로 수행한 작업이라 코드·흐름 정의·서식·고객 자료는 올리지 않고, **어떤 일을 했고 무엇을 판단했는지만** 적었다.

## 요구

- 매달 계약 인원에게 급여명세서를 올리고, 월별로 관리하고, 메일로 보내고, 보냈는지 표시한다.
- 계약 내용을 표준 근로계약서 서식에 자동으로 채운다(수기 작성 부담과 감사 대응).
- 계약 폼에서 인재·고객·포지션을 고르면 관련 정보가 자동으로 채워져, 같은 정보를 여러 번 입력하지 않게 한다.

## 한 일

### 1. 급여명세서 관리 — 관리 단위부터 다시 정함

- 계약에 파일 칸을 붙이는 안, 사람 기준으로 관리하는 안을 검토했다. 명세서는 매달 나오고 한 사람이 동시에 여러 계약을 가질 수 있어 둘 다 맞지 않았다. **"계약 1건 × 월 = 1행"** 으로 별도 테이블을 설계했다.
- 매달 쌓이는 PDF가 데이터베이스 용량을 잡아먹지 않도록 **파일은 SharePoint 문서 라이브러리**에 두고, 데이터베이스에는 정보와 파일 위치만 남겼다.
- 잘못 올린 명세서가 바로 나가지 않도록 **등록과 발송을 버튼 둘로 분리**해, 담당자가 검토한 뒤 보내게 했다.
- 파일 이름 규칙과 같은 파일의 버전 관리, 계약 화면 안의 월별 명세서 이력 탭을 만들었다.
- 급여월은 날짜 선택이 맞지 않아 "연-월" 형식 검증으로 바꿨다. 선택 목록을 동적으로 만드는 방법은 플랫폼 제약으로 쓰지 않았다.

### 2. 근로계약서 자동 작성

- 계약 형태가 표준 근로계약이면 입력 영역이 나타나고, 저장하면 흐름이 Word 서식에 값을 채워 SharePoint에 저장한다.
- 담당자가 화면 버튼으로 직접 만들 수 있는 경로도 추가했다(확인 창 → 흐름 호출).
- 예외 처리: 필수값 누락은 앱에서 막고, 수정 시에는 새 문서를 만든다. 서식 파일이 없으면 알림 메일을 보내고 종료한다. 파일명에 시각을 넣어 덮어쓰기를 막았다.

### 3. 폼 자동 채움

- 계약·급여 폼에서 인재·고객·영업기회·계약을 고르면 관련 테이블에서 주소, 연락처, 근무 장소, 업무 내용 등을 읽어 채우는 웹 리소스 4종을 만들었다.
- 급여 항목 숫자 검증을 넣었고, 계약을 고를 때 번호 대신 계약명으로 보이고 검색되도록 조회 화면을 정리했다.

## 막힌 것과 해결

- Word 서식을 고쳐도 흐름이 예전 서식 구조를 기억하는 문제는 액션을 다시 추가해 서식을 새로 읽혀 해결했다.
- 자동 채움 값이 비는 문제는 양쪽 테이블의 실제 열 이름과 형식을 뽑아 대조해 바로잡았다.
- 빈 값 때문에 흐름이 실패하는 문제는 빈 값과 날짜를 미리 처리해 막았다.
- 다른 테이블의 계산 열이 참조해 열이 지워지지 않는 문제는 참조 관계를 찾아 순서대로 정리했다.
- 버튼에서 흐름을 부를 때 생긴 요청 형식 불일치를 찾아 맞췄다.

## 결과

- 매달 반복되던 명세서 보관·발송과 계약서 작성이 화면 버튼과 흐름으로 처리된다.
- 처음 안을 고집하지 않고 관리 단위와 저장 위치를 요구에 맞게 다시 정한 과정을 기록으로 남겼다.
